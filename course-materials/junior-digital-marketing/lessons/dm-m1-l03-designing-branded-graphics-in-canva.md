## Why Branded Graphics Matter

Consistent visuals make a brand instantly recognizable and build trust. As a junior social media assistant, you'll produce many graphics quickly, so a reliable workflow in Canva is essential. The goal is speed *and* consistency.

## Setting Up Your Brand Foundation

Before designing, gather your brand assets:

- **Colors**: Primary, secondary, and accent hex codes (e.g., `#1A73E8`).
- **Fonts**: One heading font and one body font. Avoid using more than two or three.
- **Logo**: Have versions for light and dark backgrounds (PNG with transparent background).

In Canva, use **Brand Hub** (Brand Kit) to store these so they appear in every design. Pro accounts allow full brand kits; free accounts can still save colors and upload fonts/logos to a folder.

## Choosing the Right Size

Always start with the correct dimensions — resizing later distorts layouts.

- **Instagram/Facebook post**: 1080 x 1080 px (square) or 1080 x 1350 px (portrait)
- **Stories/Reels**: 1080 x 1920 px (vertical, 9:16)
- **Facebook/Instagram ad**: 1080 x 1080 px is safe; check placement specs
- **LinkedIn post**: 1200 x 627 px (landscape)

Use Canva's template search by typing the platform name to auto-load correct sizes.

## Core Layout Principles

Great graphics follow a few timeless rules:

1. **Alignment** — line up text and elements to an invisible grid. Use Canva's guides and snap lines.
2. **Contrast** — make text readable against backgrounds; dark text on light, or add an overlay on busy photos.
3. **Hierarchy** — the most important message should be biggest. Headline > subhead > body > CTA.
4. **Whitespace** — don't crowd the canvas. Negative space increases readability.
5. **Repetition** — repeat colors, fonts, and shapes across a series for a cohesive feed.

## Working with Templates

Templates speed up production. To stay on-brand:

- Swap template colors for your brand palette.
- Replace default fonts with your brand fonts.
- Drop in your logo and real photos.
- Keep the underlying layout/grid but make the content yours.

Never post a template with placeholder text or default branding still visible.

## Adding a Clear Call-to-Action (CTA)

Most marketing graphics need an action: *Shop Now*, *Learn More*, *Swipe Up*, *Link in Bio*. Make the CTA visually distinct using a button shape or contrasting color.

## Exporting Correctly

- **PNG**: best for graphics with text and crisp edges.
- **JPG**: smaller files, good for photo-heavy posts.
- **MP4/GIF**: for animated posts or stories.

Name files clearly (e.g., `IG_post_summer-sale_2024-06.png`) and organize them in dated folders for easy reuse.

## Quick Production Workflow

1. Pick correct size.
2. Apply brand kit.
3. Choose/adapt a template.
4. Add headline, supporting text, and CTA following hierarchy.
5. Check alignment, contrast, spacing.
6. Export in the right format and name the file.
